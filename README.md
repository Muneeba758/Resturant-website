# 🍽️ Restaurant Website

## 📌 About
This is a responsive Restaurant Website built to showcase food items, menu categories, and restaurant information in an attractive and user-friendly design. The main purpose of this project is to provide a smooth online experience for customers to explore the restaurant easily.

## 🚀 Features
- Home page with attractive layout
- Menu section with food categories
- About restaurant section
- Contact form for customers
- Easy navigation between pages
- Clean and modern UI design

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  

## 📂 Project Structure
Restaurant-Website/
│
├── index.html  
├── style.css  
├── script.js  
├── images/  
└── README.md  

## ▶️ How to Run
1. Download or clone this repository  
2. Open the project folder  
3. Open `index.html` in any browser  
4. Website will run successfully
